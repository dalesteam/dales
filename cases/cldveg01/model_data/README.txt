This directory contains the following cases:

TRANS - transparent clouds: cases starting with 1x0 (where ‘x’ is a number based on wind speed, see below)
INST - instantaneous plant response: cases starting with 2x0
DOMAIN - domain averaged temporal surface fluxes based on INST, cases with 2x8
ASYM - asymmetric surface response (5min close, 10min open), cases start with 6x0


WIND cases are denoted as follows:

0.0 m/s - x0x (for instance, TRANS with no wind is 100)
2.5 m/s - x2x
5.0 m/s - x3x
7.5 m/s - x4x
10.0m/s - x5x
